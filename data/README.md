## 修正過程中發現並排除的問題（供後續參考，避免重蹈覆轍）

1. **v1（猜測TWSE/TPEx端點）**：沒有實測就直接用，端點格式部分猜對部分猜錯。
2. **v2（改用yfinance）**：發現Yahoo Finance的歷史收盤價會回溯調整股票分割與股票股利，導致歷史價格失真。例如總太(3056)因2023~2025年三次股票股利（換算股數倍率約1.98倍），2022年申購當時市價被回溯調整成約一半；材料-KY因2025年「一股拆十股」的面額變更，歷史價格被錯誤調成約1/10。
3. **v3（改回TWSE/TPEx官方端點）**：TWSE的`STOCK_DAY`端點驗證通過（315筆，僅上市類別）；但TPEx端點（`tpex_mainboard_daily_close_quotes`）對舊日期查詢實測發現**不會理會查詢的日期參數，直接回傳最近一天的資料**（曾用尚凡5278驗證：查詢2020/01/08，API回應的`Date`欄位卻顯示查詢當下的日期），這部分資料全部作廢。
4. **v4（改用FinMind）**：用總太、尚凡、漢測本身三筆已知正確答案，驗證涵蓋上市、上櫃、興櫃三個市場皆準確，改採此資料源。過程中遇到FinMind免費額度限制（每小時請求數上限，未登入或免費帳號額度較低），用「續跑機制」分批抓取完成，並用已驗證的v3(僅TWSE部分)資料與v4結果合併，減少重複呼叫API的次數。

## 已知限制
- 剩餘37筆查無資料的公司，尚未逐一排查原因（特別股/下市/資料缺漏），暫不影響整體分析。
- 拿這份資料訓練的迴歸模型，套用到漢測（承銷價2,250元）時，漢測的承銷價已經超出樣本歷史最高值（鴻勁1,495元）約50%，屬於樣本外插，估計結果的不確定性高於模型R²數字本身所呈現的。
