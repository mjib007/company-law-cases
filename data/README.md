# data/ 資料夾說明

## 檔案
- `ipo-lottery-history-2020-2026.csv`：原始資料，2020~2026年公開申購抽籤日程，來源：[證交所公開申購公告](https://www.twse.com.tw/zh/announcement/public.html)
- `ipo-lottery-history-2020-2026-with-price.csv`：加上「申購結束日市價」欄位的版本

## 「申購結束日市價」欄位的資料品質狀況（重要，使用前請先看）

965筆資料中，**目前只有「資料來源」欄位標示為`TWSE`的315筆經過人工逐筆核對驗證，確認無誤**。其餘部分：

- **`資料來源`為空白的309筆**：屬於「初上市／初上櫃」類別，申購當時公司尚未正式掛牌（興櫃階段），目前沒有驗證過的官方資料源，刻意留空，不是抓取失敗。
- **`資料來源`為`TPEx`的305筆**：**目前已知不可靠，不建議使用**。實測發現所用的官方端點（`tpex_mainboard_daily_close_quotes`）對舊日期查詢不會真的回傳當時的歷史資料，而是回傳最近一天的資料（曾用尚凡5278在109/01/08的案例驗證出這個問題：API回傳的`Date`欄位顯示的是查詢當下的日期，而非要求的歷史日期）。
- **其餘約33筆抓取失敗**（不含上述兩類）：多為特別股代碼（如甲特、乙特）、公司已下市或合併，TWSE端點查無資料。

## 修正過程中發現並排除的問題（供後續參考）

1. 最初版本使用yfinance抓價格，發現Yahoo Finance的歷史收盤價會回溯調整股票分割與股票股利，導致歷史價格失真（例如總太3056因2023~2025年三次股票股利，2022年申購當時市價被回溯調整成約一半）。改用TWSE/TPEx官方逐日成交資訊後解決此問題（僅限TWSE部分）。
2. 以下幾筆經使用者人工查證，確認TWSE抓取結果正確：
   - 總太(3056) 111/07/19：26.70元
   - 愛山林(2540) 114/03/17：86.3元
